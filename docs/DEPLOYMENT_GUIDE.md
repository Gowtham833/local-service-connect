# ServiConnect Deployment Guides

The deployment instructions have been separated into distinct guides based on your preferred approach:

1. [Automated CloudFormation Deployment Guide](./DEPLOYMENT_GUIDE_CLOUDFORMATION.md)
   - Use this if you want to deploy the infrastructure as code using AWS CloudFormation.
   - Recommended for clean, repeatable deployments and CI/CD pipelines.

2. [Manual AWS Console (GUI) Deployment Guide](./DEPLOYMENT_GUIDE_GUI.md)
   - Use this if you want to deploy everything click-by-click in the AWS Management Console without writing any code.
   - Recommended for absolute beginners learning AWS.
