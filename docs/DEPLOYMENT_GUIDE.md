# ServiConnect Deployment Guides

The deployment instructions have been split into two separate guides depending on your preferred approach:

1. [Automated Terraform Deployment Guide](./DEPLOYMENT_GUIDE_TERRAFORM.md)
   - Use this if you want to deploy the entire infrastructure automatically using Infrastructure as Code.
   - Recommended for production and CI/CD pipelines.

2. [Manual AWS Console (GUI) Deployment Guide](./DEPLOYMENT_GUIDE_GUI.md)
   - Use this if you want to deploy everything click-by-click in the AWS Management Console without writing any code.
   - Recommended for absolute beginners learning AWS.
